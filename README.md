# BBPlayer-car

支持手机横屏、平板和 Android 车机宽屏界面的 BBPlayer 分支。

## 界面适配

- **横屏工作区**：左侧浏览首页、音乐库、搜索、歌单和设置，右侧常驻播放器；左侧切换页面不关闭右侧播放器。
- **手机横屏**：使用小封面和紧凑播放控制；高度不足时隐藏次要内容，优先保留核心播放操作。
- **平板与车机**：沿用左右分区，右侧宽度设有上限，更多空间用于浏览内容。
- **歌词界面**：在左侧打开歌词，右侧继续提供播放操作，歌词区域不叠加第二套播放控件。
- **触摸操作**：切歌、导航及辅助按钮提供 48dp 触摸区域。
- **弹窗**：宽屏下居中显示并限制最大宽度。

布局根据实际可用宽高切换；可用宽度不足 600dp 时保留单栏，竖屏沿用原有导航。实际显示与操作效果需在目标手机、平板和车机上验证。
