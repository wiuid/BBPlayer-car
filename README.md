# BBPlayer-car

支持手机横屏、平板和 Android 车机宽屏界面的 BBPlayer 分支。

## 界面适配

- **手机横屏**：根据可用高度启用紧凑布局，缩小封面、让歌曲信息独立滚动，并减少播放控制区间距。
- **平板与车机**：播放器采用左右分栏，充分利用宽屏空间。
- **歌词界面**：低高度横屏使用横向控制栏，为歌词预留显示空间；旋转屏幕后自动更新底部控制区高度。
- **触摸操作**：切歌按钮提供 48dp 触摸区域，辅助按钮支持换行。
- **弹窗**：宽屏下居中显示并限制最大宽度。

布局根据实际可用宽高切换，兼容竖屏。当前适配重点为播放器、歌词页和通用弹窗，实际显示与操作效果需在目标手机、平板和车机上验证。
